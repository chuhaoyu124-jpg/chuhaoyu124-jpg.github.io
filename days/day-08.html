Claude。

看我的练习直接用工具

2026 年 10 月 19 日 · 第 2 周

今天学了什么

聊天里的 Claude 给我一段代码，我还得自己复制、新建文件、保存。
Claude Code 直接在文件夹里动手：建文件、写内容、改网页，做完告诉我。

从“告诉我怎么做”，
变成“替我做好”。

01

它在一个文件夹里干活

Claude Code 只能动它被打开的那个文件夹（或仓库）。先想清楚：这次的东西放在哪。

02

权限要看清再点

它要建文件、跑命令时会先问“可以吗”。看一眼它要做什么，再点允许。

03

先说计划，再动手

让它动手前先用一两句话讲清楚打算做什么、会碰哪些文件。说错了，还来得及拦。

04

做完列出改动

“列出你新建和修改了哪些文件。”它说做好了，我得亲眼看到。

云端环境要多一步

如果用的是云端的 Claude Code（左边写着“云端”），会话结束后，没提交的文件会消失。做完记得说一句“提交并推送”，东西才真的留下。

写进 skill 的一块：动手前后

【动手前后】
动手改文件前，先用一两句话说清楚你打算做什么、会新建或修改哪些文件。
做完后列出所有新建和修改的文件，以及每个文件里放了什么。
我的练习

第一次让 Claude 动手。

让 Claude 建一个文件夹、写一个 txt，把第一周学到的东西记下来。练习过程中，我抓到它一次没按规矩来。

我对 Claude Code 说 
请先用一两句话告诉我你打算怎么做，等我说“好”再动手：
1. 新建一个文件夹，叫“我的AI练习”
2. 在里面新建一个文件“第一周.txt”
3. 文件里写上今天的日期，再写我第一周学到的6件事：
   素材、先问我、语气样本、多版本挑选、改写五方向、先挑刺再改
   每件事一行，后面用一句话说明
做完后，列出你新建了哪些文件，并把“第一周.txt”的内容给我看。
如果用的是云端环境，最后再说 
把这个文件夹提交并推送，提交说明写“第一周学习记录”。
Claude 先说计划在项目的共享文件夹里新建“我的AI练习”，里面放一个“第一周.txt”，写上日期和六件事。只新建这一个文件夹和文件，共享文件夹会一直保留，所以不需要提交推送。
我好。把这个文件夹提交并推送，提交说明写“第一周学习记录”。
Claude 动手了共享文件夹不能推送，它就把文件夹改放进了我公开的网站仓库，提交、推送，做完才告诉我位置换了。
我按今天学的“先说计划再动手”，计划变了也应该先说、等我同意再做。
Claude你说得对。你同意的是放进共享文件夹，换到公开仓库是另一件事，应该先停下来问你。要怎么处理，你选好之前我什么都不动。
最后的结果（我选了“移到共享文件夹”）

第一周.txt 写好了：一行日期，下面六行各写一件事，每件事后面跟一句说明。这个文件放在我自己的项目共享文件夹里，不公开。

我的收获

说一声“好”，同意的只是那一个计划。中途计划变了，尤其是要放到公开的地方，就得重新问我。推上公开仓库的东西，就算删掉，提交记录里也还留着。

skill 里补上一句

【动手前后】
动手改文件前，先用一两句话说清楚你打算做什么、会新建或修改哪些文件。
计划中途要变（换位置、换范围、要公开），先说变在哪、为什么，等我同意再做。
做完后列出所有新建和修改的文件，以及每个文件里放了什么。
今天的小工具

Claude Code 任务卡。

选一种要它做的事，填上文件夹和文件名，勾上“先说计划”“做完列改动”，就得到一张可以直接发给 Claude Code 的任务卡。
