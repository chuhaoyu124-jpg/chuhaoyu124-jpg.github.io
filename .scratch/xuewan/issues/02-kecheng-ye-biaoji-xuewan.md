# 02: 在课程页标记「学完」

**What to build:** 读者在任何一课的页面底部点「标记为学完」，这一课就被记为**学完**；再点一次可以取消。记录保存在读者自己的浏览器里，刷新或几天后再来都还在。背后是一个只负责“哪几课学完了”的小模块，配有 Node 自动化测试。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 新增「学完记录」小模块：可查询某课是否学完、切换某课的学完状态（返回切换后的状态）；存储对象可注入（只需 get / set），同一份文件既能在浏览器以普通 script 引入，也能被 Node 加载
- [ ] 按 Day 编号记录；存储读写抛错时不抛出、视为未学完；存的值损坏或不是数组时视为空
- [ ] 仓库新增最小 `package.json`，`npm test` 用 `node --test` 运行，不装第三方依赖
- [ ] 测试覆盖：初始未学完；切换一次学完、再切换取消；用同一个假存储新建实例后记录仍在；多课互不影响；存储抛错不崩；损坏值视为空
- [ ] 每课底部、上一课 / 下一课之上，由全站脚本自动插入按钮，新课页面无需手写
- [ ] 未学完时按钮显示「标记为学完」；学完后显示「✓ 已学完」，悬停 / 长按提示「再点一次取消」
- [ ] 按钮旁有一行小字「记录只保存在这个浏览器里」
- [ ] 点击后用现有小提示弹出「学完 Day N 🎉」，取消时弹出「已取消学完」
- [ ] 无痕模式或禁用网站数据时页面照常可用，点击按钮不报错
- [ ] 不违反页面 CSP（同源脚本、无网络请求）
- [ ] README 写明测试怎么跑
- [ ] 浏览器验证：打开 Day 7 点按钮 → 刷新仍是「✓ 已学完」→ 再点取消；手机尺寸和深色外观下显示正常
