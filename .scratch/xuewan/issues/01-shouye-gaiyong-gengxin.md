# 01: 首页改用「更新」一词

**What to build:** 读者在首页看到的“进度”文字改成「更新」，明确它表示 Haoyu 已经更新了几课，而不是读者自己学完了几课。为后面加入「学完」做准备，避免两个概念混淆（见 `GLOSSARY.md`）。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] 首页顶部数字的标签「四周课程进度」改为「已更新」，数字本身的算法不变
- [ ] 路线图每周的「已完成 N / M 天」改为「已更新 N / M 天」；尚未开始的周仍显示「即将解锁」
- [ ] 网站其它地方（README 等）凡是用“完成 / 进度”指更新课数的说法，统一改为「更新」
- [ ] 在浏览器打开首页确认文字正确，手机、iPad、电脑三种布局都不错位
