# 03: 首页显示学完进度

**What to build:** 读者打开首页，顶部能看到「已学完 N / M」（M = 已更新的课数），学完的课在课程卡上显示 ✓，一眼知道自己跟上了多少、下一课该看哪一课。

**Blocked by:** 02（在课程页标记「学完」）

**Status:** ready-for-agent

- [ ] 「学完记录」模块新增计数：给定已更新的课列表，返回学完数和已更新数；不在已更新列表里的 Day 不计入，学完数不超过已更新数
- [ ] 计数的 Node 测试：初始 0 / M；标记后数字增加；列表外的 Day 不计入
- [ ] 首页顶部从三个数字变成四个，新增「已学完 N / M」；还没学完任何一课时显示「已学完 0 / M」
- [ ] 新更新一课后分母自动变大，无需手动改
- [ ] 学完的课在首页课程卡上显示 ✓；卡片点击行为不变，不能在首页标记学完
- [ ] 四个数字在手机、iPad、电脑三种布局下都不挤、不错位，深色外观正常
- [ ] README 增加「学完」一节，说明按钮、首页数字和记录只存在本地浏览器
- [ ] 浏览器验证：在 Day 7 标记后回首页看到「已学完 1 / 7」和 ✓；取消后变回 0 / 7

## Comments

- 2026-10-18 已实现（分支 `xuewan`）。「已学完」和其它三个数字同样排版：大号「N / M」，下面一行小字「已学完」。✓ 在课程卡右上角，手机列表里 meta 行给它留了位置。`assets/xuewan.js` 没加载到时首页照常渲染，只是不显示「已学完」。浏览器存储的读写（`browserStore`）也放进了学完记录模块，课程页和首页共用。
