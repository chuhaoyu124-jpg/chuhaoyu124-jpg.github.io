# Haoyu 的 AI 工具箱

每天学一点，每天多一个能用的小工具。网址：https://chuhaoyu124-jpg.github.io

风格参照 Apple 官网：白色底色、近黑文字、天蓝色辅助色，毛玻璃导航，滚动淡入，深色模式跟随系统。

## 结构
- `index.html` 首页：大标题、最新一课展示、全部课程、四周路线图。内容全部来自 `assets/days.js`
- `days/day-NN.html` 每天一页
- `about.html` 关于页
- `assets/style.css` 设计系统；`assets/site.js` 导航、淡入动效、`copyText()` 复制
- `assets/xuewan.js` 学完记录（读者给哪几课标了「学完」）
- `scripts/` 新课一键生成（`npm run new-day`，见下面「每天新增一课」）；`test/` 是测试，`package.json` 只用来跑这两个命令

## 每天新增一课

先用一条命令生成这一课的**草稿**（术语见 `GLOSSARY.md`）：

```bash
npm run new-day -- --title "让 Claude Code 帮我建文件夹" --summary "一句话说清要什么，它替你建好整套文件夹。" --glyph 建 --tool "文件夹提示词" --keywords "文件夹 终端"
```

- 必填 `--title`（标题）、`--summary`（一句话总结）、`--glyph`（图标上的一个字）、`--tool`（小工具名）；选填 `--grad`（图标渐变，不填用默认暖橙）、`--keywords`（搜索词）
- Day 编号自动取最新一课 +1，日期取今天，第几周和当周主题按路线图算；需要时可以用 `--day`、`--date` 改
- 它会：以最新一课为底新建 `days/day-NN.html`（head、标题区、pager、页脚都填好，三个版块只留骨架和【待写】），在 `assets/days.js` 最前面加一条，把上一课 pager 的「明天见」改成链接
- 页面已存在、跳号、超出路线图、上一课找不到「明天见」时会拒绝，一个文件都不改
- 它不提交也不推送

然后把页面里的【待写】全部写完（大标题的换行、lead 也可以顺手改），跑 `npm test` 变绿，再推送到 main。推送了才算更新。

页面一共五块（手写的三个版块可以参考 Day 1 的"三次尝试对比"写法和 Day 2 的"采访对话"写法）：
1. `lesson-hero`：渐变图标（一个字）、eyebrow「Day N · 第几周主题」、大标题、一句话总结
2. `section alt #learn` 今天学了什么：`statement` 大字 + `features` 要点格子（最关键的一格用 `hl`）+ `pull` 金句 / `note-grid`
3. `section #practice` 我的练习：Haoyu 的真实提示词、AI 输出、提问和收获。截图一律转写成文字，不贴原图。AI 自己补的句子用 `<mark>` 标出
4. `section alt #tool` 小工具：`studio` 两栏，左边 `panel-card` 表单（`seg` 场景切换、`toggle` 开关），右边 `preview` 输出 + 复制按钮。纯前端，不调任何 API
5. 底部 `pager` 指向上一课和下一课

其中 1 和 5 由命令生成，2、3、4 是你手写的部分。

链接一律写成 `index.html` / `../index.html`，不要写 `./` 或 `../`：在电脑上直接双击打开文件时，`./` 会打开文件夹列表而不是首页。

每个页面的 `<head>` 里都要保留 `Content-Security-Policy` 和 `referrer` 两行 meta（从模板复制即可）：它们禁止页面加载外部脚本、发送网络请求和提交表单。小工具只能是纯前端，不引用任何外部网址的脚本或字体。

## 分享预览与页脚

- 每个页面 `<head>` 里有一组 `og:` meta（标题、描述、`assets/og.png` 预览图）和 `apple-touch-icon`，链接发给朋友时会显示卡片。新页面从上一课复制即可，把 `og:title`、`og:description`、`og:url` 改成这一课的。
- 页脚是面包屑：`Haoyu 的 AI 工具箱 › Day N · 标题`，下一行是版权。
- 课程页导航里的“笔记 / 练习 / 工具”会随滚动自动高亮，对应版块的 id 必须是 `learn`、`practice`、`tool`。
- 标题里不想被拆开的词组用 `<span class="nb">…</span>` 包起来。
- `404.html` 用以 `/` 开头的绝对路径，本地直接打开没有样式，线上正常。

## 动效

动效集中在 `assets/style.css` 末尾“动效 2.0”和 `assets/site.js` 里，新页面不用额外写：页面切换淡入淡出（课程图标会飞到课程页顶部）、大标题虚化浮现、卡片跟随鼠标倾斜、数字滚动、课程页阅读进度条。课程页顶部大图标保持 `class="glyph reveal"` 写法即可。系统开启“减弱动态效果”时这些都会自动关闭。

## 搜索、外观与小功能（3.0）

都在 `assets/site.js` 末尾和 `assets/style.css` 末尾，新页面不用额外写：

- **搜索面板**：按 `⌘K` / `Ctrl K` 或 `/`，或点导航右侧放大镜。能搜课程、小工具、页面，也能切换外观。数据来自 `assets/days.js`，每课的 `keywords` 字段写几个搜索词（比如“闲鱼 台灯”），搜不到正文里的词时就靠它。
- **外观切换**：导航右侧按钮在“跟随系统 / 浅色 / 深色”之间切换，记在浏览器里。每个页面 `<head>` 里有一行读取它的小脚本，防止打开时闪一下，新页面从模板复制即可。
- **代码块复制**：所有 `<pre class="code">` 右上角自动出现“复制”按钮。
- **课程页**：标题下自动加上“约 N 分钟读完”和“分享这一课”；键盘 `←` `→` 翻到上一课 / 下一课。
- **标记为学完**：每课底部自动出现按钮，详见下面「学完」一节。

## 按设备分别设计（3.1）

网站会根据“屏幕多宽 + 是不是触屏”自动判断是手机、iPad 还是电脑，界面各不相同（`assets/style.css` 末尾“3.1”一节，底部标签栏和浮动按钮由 `assets/site.js` 自动生成）：

| | 手机 | iPad | 电脑 |
|---|---|---|---|
| 导航 | 底部标签栏（首页 / 课程 / 搜索 / 关于；课程页是 首页 / 笔记 / 练习 / 工具 / 搜索） | 顶部居中的胶囊标签栏，当前版块高亮 | 顶部右侧细导航 + `⌘K` 提示 |
| 课程卡 | App Store 式列表，图标在左 | 两列（竖屏）/ 三列（横屏） | 三列网格 |
| 小工具 | 表单在上，滚动时底部浮出“复制提示词” | 竖屏也左右并排，右边预览跟着滚 | 左右并排 |
| 交互 | 按下轻缩，打字时自动收起底部栏 | 按下轻缩，44px 大触控区 | 悬停倾斜、暖光、快捷键 |

每个页面的 `viewport` 带 `viewport-fit=cover`，并可“添加到主屏幕”当 App 用，新页面从模板复制即可。

## 我的卡通形象

关于页（“认识我”）顶部是 Haoyu 的卡通形象：`assets/me.jpg` 是 AI 生成的马里奥式圆润卡通头像（按本人照片反复校对过五官），由 `assets/avatar.js` 的图片模式驱动。不放图片时它也能用纯 SVG 画一个备用形象。

- 眼睛跟着鼠标走，头也会轻轻转向；手机上跟着手指，没人碰时会自己东张西望，还会不时眨眼
- 鼠标靠近：笑得更开；放到头像上：眯眼大笑，第一次会说“嗨～我是 Haoyu”
- 鼠标移到链接、按钮上：挑眉好奇；鼠标甩得很快：吃惊张嘴
- 9 秒没动静：犯困冒 Zzz，一动就醒（“啊，我没睡！”）
- 点他：眨眼 + 冒爱心 + 说一句话，连戳 5 下会害羞脸红

想放到别的页面：加 `<button type="button" class="me" data-avatar aria-label="Haoyu 的卡通形象，点一下打个招呼"></button>`（大号再加 `me-lg`），再引入 `assets/avatar.js`。肤色、发色、衣服颜色都在 `svg()` 开头的 `<defs>` 渐变里改。

## 学完（读者自己的记录）

读者可以给每一课标记「学完」（术语见 `GLOSSARY.md`：「更新」是 Haoyu 发了一课，「学完」是读者读完了一课，两者不要混用）：

- **课程页**：底部自动出现「标记为学完」按钮，再点一次取消（`assets/site.js` 里的 `mountXuewan`）；浏览器不让保存时提示“没能保存”，不假装学完
- **首页**：顶部第四个数字「已学完 N / M」，M 是已更新的课数，新课一上线分母自动变大；学完的课在课程卡右上角打 ✓，卡片本身还是只用来打开这一课
- 记录只存在读者自己的浏览器里（页面 CSP 禁止网络请求），换设备或清掉网站数据就没了；新增一课不用为「学完」做任何事

## 测试

课程页底部的「标记为学完」由 `assets/site.js` 自动插入，记录逻辑在 `assets/xuewan.js`（只存在读者自己的浏览器里）。这部分有自动化测试，用 Node 自带的测试工具，不用装任何依赖：

```bash
npm test
```

测试文件在 `test/` 里。术语见 `GLOSSARY.md`。

`npm test` 也会测「新课一键生成」（`scripts/`），并检查 `assets/days.js` 里列出的每一课都没有【待写】。所以写草稿期间测试是红的，这是正常的：红色就是在提醒你草稿还没写完，先别推送。
