# Haoyu 的 AI 工具箱

每天学一点，每天多一个能用的小工具。网址：https://chuhaoyu124-jpg.github.io

## 结构
- `index.html` 首页卡片墙，内容来自 `assets/days.js`
- `days/day-NN.html` 每天一页：上面是笔记，下面是小工具
- `about.html` 关于页
- `assets/style.css` 共用样式（浅色/深色）

## 每天新增一课
1. 复制上一天的页面为 `days/day-NN.html`，改笔记和工具
2. 在 `assets/days.js` 的最前面加一条
3. 推送到 main，GitHub Pages 自动上线
